# MP v4.6 — CPU 숏티지 허구 판단 → CPU 익스포저 UW + NBIS 인상 — 2026-08-24

> 지시: **"CPU 숏티지는 허구다 → UW"** + **"NBIS는 올려라."**
> 해석: 숏티지 내러티브로 이익 추정·멀티플이 부풀려진 CPU 익스포저를 언더웨이트.
> 포트 내 직접 노출: **AMD**(EPYC 서버·클라이언트 CPU가 이익의 핵심 축), **ARM**(CPU IP 로열티).
> INTC는 이미 제외(0%) — 이번 판단과 정합. ±1.3%p 제로섬, 합계 100.0 유지, 107종목 불변.

## 변경

## 논리 정합 점검

- **연산 레이어 최종 구도(v4.4→4.6 누적)**: NVDA −0.7, AVGO −0.2, AMD −0.6, ARM −0.3 —
  **칩 설계사 전반이 중립~UW**가 됐다. OW는 MRVL(비구글 ASIC)·CBRS(대안 아키텍처)와
  **중립 부품·인프라**(MU·TSM·광통신·전력·냉각)에 집중된다. "무기상을 사고 진영은 사지
  않는다"가 이제 GPU/CPU/구글ASIC 전부에 일관 적용된다.
- 수급 정합: GS 자료에서 AMD는 MF 순매수/HF 순매도로 갈렸던 종목 — 이번 UW는 HF 편에 선다.
- **되돌림 조건**: 서버 CPU 리드타임·가격 데이터가 2개 분기 연속 타이트하게 나오면(숏티지
  실재 입증) AMD·ARM UW 해제. 반대로 재고 급증·가격 인하 확인 시 UW 유지·심화.
- 상세 보고서(v4.5판) §4-①·§7 아키텍처 게이트에 CPU 조항 추가는 다음 통합 개정에서 반영.
