## 왜 세션을 새로 여는가

이전 세션 컨테이너의 egress 정책이 아래를 **403(policy denial)**로 막았다. 정책을 바꿔도
**이미 실행 중인 컨테이너에는 소급 적용되지 않아** 새 세션이 필요했다.

| 대상 | 용도 | 이전 세션 결과 |
|---|---|---|
| `benopenclaws-mac-mini.taile4cc1e.ts.net` | 미니 API(퍼널) — 원장 직접 조회 | 403 |
| `controlplane.tailscale.com`, `login.tailscale.com` | tailnet 합류 | 403 (tailscaled 빌드·기동까지 성공했으나 등록 불가) |
| `query1/query2.finance.yahoo.com` | yfinance | 403 |
| `100.76.152.112:8000` (tailnet 직결) | 미니 API | 타임아웃(샌드박스가 tailnet 밖) |

**새 세션에서 가장 먼저 할 일 — 도달성 확인:**

```bash
curl -sS -o /dev/null -w "mini:%{http_code}\n" --max-time 20 \
  https://benopenclaws-mac-mini.taile4cc1e.ts.net/api/source
curl -sS -o /dev/null -w "yahoo:%{http_code}\n" --max-time 20 \
  "https://query1.finance.yahoo.com/v8/finance/chart/AAPL?range=5d&interval=1d"
```

- **미니(ts.net)가 200이면** → 미니 원장이 1순위 소스. `/api/source`로 사용 가능한 경로를
  확인하고, 미국 종목 밸류·재무 경로가 없으면 `/api/us/session`·`/api/quotes/*`로 가격을
  받아 TE·베타·MDD·샤프를 계산한다.
- **야후가 200이면** → `mp_quant_metrics.py`를 그대로 실행하면 전부 나온다.
- **둘 다 403이면** → 정책이 아직 반영 안 된 것. 도메인을 와일드카드 없이 정확히
  (`benopenclaws-mac-mini.taile4cc1e.ts.net`) 넣었는지 확인 요청.
- tailscale 클라이언트가 필요하면: `GOBIN=/usr/local/bin GOFLAGS=-mod=mod go install
  tailscale.com/cmd/tailscale@latest tailscale.com/cmd/tailscaled@latest` (goproxy는 열려 있음, 약 3분)
