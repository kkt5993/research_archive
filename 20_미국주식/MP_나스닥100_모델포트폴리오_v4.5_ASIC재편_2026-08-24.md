# MP v4.5 — ASIC 프레임 재편(NVDA 축소·세레브라스 신규) — 2026-08-24

> 지시: **"ASIC도 좋게 본다 → NVDA도 줄이고, 세레브라스는 높여라."**
> v4.4의 논리(AVGO 축소 = 구글 종속 문제)를 상위 프레임으로 확장한다:
> **문제는 ASIC이 아니라 '누구의 ASIC이냐'였고, 이제 머천트 GPU 독점 프리미엄 쪽도 중립화한다.**

## 프레임 정리 — 연산 레이어의 최종 구도

| 축 | 판단 | 표현 |
|---|---|---|
| 머천트 GPU (NVDA) | 독점 프리미엄의 정점 통과 가능성 — ASIC 침식 인정 | **8.0 (BM −0.7, UW 전환)** |
| 구글 종속 ASIC (AVGO) | 고객(구글) 뷰 부정적 | 4.3 유지 (v4.4) |
| **비구글 ASIC (MRVL)** | AWS·MSFT — OW한 진영의 ASIC | **3.3 (+0.5)** |
| 대안 아키텍처 (CBRS 세레브라스) | 웨이퍼스케일 — 추론 속도 특화, ASIC 다변화의 순수 노출 | **신규 0.5** |
| 비NVDA 머천트 (AMD) | MI 시리즈 — 가격 대안 | **1.8 (+0.3)** |
| 아키텍처 중립 (MU·ALAB) | 어떤 칩이 이겨도 HBM·인터커넥트는 필요 | **MU 4.0 (+0.2), ALAB 0.7 (+0.1)** |

연산 레이어 내부가 "NVDA 원톱"에서 **"중립 부품 > 진영별 분산"** 구조로 바뀐다.
광통신·전력·냉각(아키텍처 무관)이 이 MP의 최대 확신층이라는 점은 그대로다.

## 변경 (±1.6%p 제로섬)

| 종목 | v4.4 → v4.5 | 사유 |
|---|---|---|
| **NVDA** | 9.4 → **8.0** | Active +0.7 → **−0.7 UW**. ASIC 우호 뷰와 정합화. v4.4의 단일종목 9.5% 상한 이슈도 해소 |
| **CBRS** | 신규 **0.5** | 세레브라스 — 웨이퍼스케일 추론. 중소형·상장 초기라 0.5 상한(BM외). **티커·유동성 확인 필요**(상장 일정이 CFIUS 지연 이력) |
| MRVL | 2.8 → **3.3** | 비구글 ASIC 대표 — 이번 프레임의 최대 수혜 포지션 |
| AMD | 1.5 → **1.8** | 비NVDA 머천트 대안 |
| MU | 3.8 → **4.0** | HBM — 아키텍처 중립 1순위 |
| ALAB | 0.6 → **0.7** | ASIC 클러스터 인터커넥트 |
| NBIS | 0.5 → **0.3** | 슬리브 재원 — 네오클라우드 내 확신 낮은 쪽 축소 |

- BM외 슬리브 16.1% — 상한 16 → **16.5%** 미세 상향(CBRS 신규 수용, 세 번째 완화. 이 이상은
  BM 재정의 사안이라 동결).
- 종목수 106 → **107**. 합계 100.0 (스크립트 검증).

## 리스크 메모

- **NVDA UW는 이 MP에서 가장 논쟁적인 콜이 됐다.** 자체 리서치(NVIDIA_분석리포트)는 Fwd
  PER 24x를 '밸류 합리화'로 봤다 — 이번 UW는 밸류가 아니라 **아키텍처 점유 전망**에 근거한다.
  NVDA가 실적 서프라이즈 + ASIC 전환 지연을 동시에 보여주면 되돌릴 조건(2개 분기).
- CBRS는 매출 집중(G42 계열 비중 높음)·상장 초기 변동성 — 0.5% 상한 고정, 분기 재점검.
- MRVL 3.3%는 종전 최대였던 고객 이탈 리스크가 더 커진 사이즈 — 이탈설 뉴스 즉시 재점검 유지.
