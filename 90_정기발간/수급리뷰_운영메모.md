# 💧 수급 (투자자별 자금흐름) 파이프라인

한국 투자자별 수급 데이터는 KRX/네이버에만 있고 클라우드에서 직접 접근이 막혀 있어,
**하이브리드**로 운영한다: 데이터 수집만 로컬, 분석·리포트는 클라우드.

## 흐름
1. **로컬(맥북, 주1회)** — `_scripts/수급_데이터수집_로컬.py` (pykrx, 호출 딜레이·재시도)
   → `수급/데이터/<주차>/netbuy_by_ticker.csv` 로 커밋/푸시
2. **클라우드(매주 토요일)** — `_scripts/수급_리포트생성.py` 로 CSV를 집계
   (투자자 세부·세부섹터·기간별 누적·가속도) → `수급/주간수급리뷰/<주차>_수급리뷰.md` 커밋

## 정확성
- 모든 숫자는 KRX 공식 데이터를 **결정론적 파이썬**이 계산(LLM 산술 배제).
- 리포트에 '세부기관 합 = 기관합계' 정합성 자동 검증 포함.

## 데이터 수집 현황 (2026-08-11 확인)

클라우드 환경에서 **금융 API 차단 범위가 넓어졌다.** 이 저장소를 갱신할 때 참고할 것.

| 소스 | 상태 | 비고 |
|---|---|---|
| **Yahoo Finance (chart API)** | ❌ **차단** | HTTP 429 지속. 직접 호출·재시도 모두 실패 |
| 네이버 금융 | ❌ 차단 | 기존과 동일 |
| Stooq | ❌ 차단 | JS 검증 페이지 반환 |
| **FRED (fredgraph.csv)** | ✅ **작동** | 미국 금리·환율·유가·실업률·CPI·하이일드·VIX 등. **금리/매크로는 여기서 받을 것** |
| **CoinGecko (public API)** | ✅ **작동** | 암호화폐 시세·시총·도미넌스·1년 일별 이력 |
| WebSearch | ✅ 작동 | 뉴스·실적·정책 확인용 |
| WebFetch | ⚠️ **주의** | 페이지는 가져오나 **요약 과정에서 숫자를 뒤섞는 사례 확인**. 정밀 수치 용도로 쓰지 말 것 |

**권장 경로**: 매크로·금리·환율 → FRED / 암호화폐 → CoinGecko / 한국 시세·실적 → **로컬 수집 스크립트**.

### 종목 시세 수집 스크립트

`_scripts/종가_수집_로컬.py` — 로컬(맥북/맥미니)에서 pykrx 로 KRX 공식 종가를 받아
`_manifest/데이터/` 에 CSV·JSON 으로 떨어뜨린다. 사용법은 [`_scripts/README.md`](../_scripts/README.md).

```bash
~/.venv/krx/bin/python _scripts/종가_수집_로컬.py --from-docs 10_국내주식/22_반도체 --out 반도체
```

**종목별 OHLCV 는 로그인 없이 되지만, PER·PBR·시가총액·지수·일괄조회는 KRX 로그인(`KRX_ID`/`KRX_PW`)이 필요하다.**
